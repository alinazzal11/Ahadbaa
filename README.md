# Alhadbaa Pharmacy Manager

Version 1.4.3

## Highlights
- English / Arabic interface
- RTL support
- Excel-style financial reports
- CSV and Excel exports
- Offline-capable PWA
- Local device storage

## Run locally
Open `index.html` with Live Server or any local web server.

## Currency rule
All values remain in the format `1,234 IQD` in both languages.
