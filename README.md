# Alhadbaa Pharmacy Manager v1.3

A lightweight offline-first pharmacy financial manager built with HTML, CSS and JavaScript.

## Version 1.3 highlights
- Instant English / Arabic language switch
- Full right-to-left Arabic interface
- Language preference saved on the device
- Currency always uses Western digits and the format `1,234 IQD`
- Combined Sales vs. Owner Withdrawals report chart
- Separate Sales, Profit and Owner Withdrawals trend charts
- Charts and report cards follow the selected date range

## Included modules
- Dashboard
- Daily sales and profit
- Supplier payments with discount/bonus calculation
- Expenses
- Employee advances
- Owner withdrawals
- Date-range reports and CSV export
- JSON backup and restore
- Dark mode
- Installable iPhone/desktop web app

## Run locally
Open `index.html` directly in Chrome or Edge. For development in VS Code, use the Live Server extension.

## GitHub Pages
Repository Settings → Pages → Deploy from branch → `main` and `/root`.

## Data safety
Records are stored in the browser on the current device. Export a JSON backup regularly, especially before clearing browser data or changing devices.
